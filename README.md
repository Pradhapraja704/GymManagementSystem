# Gym Management System

A web-based Gym Management System developed using React.js and Spring Boot.

## Features

- Member Management
- Trainer Management
- Attendance Management
- Trainer Assignment
- Workout Plans
- Membership Plans
- Diet Plans
- Authentication and Protected Routes

## Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- HTML
- CSS
- Axios

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API
- MySQL

## Run Backend

The backend is developed using **Java Spring Boot** in IntelliJ IDEA.

1. Open the project in **IntelliJ IDEA**.
2. Make sure **Java** and **Maven** are configured.
3. Make sure **MySQL** is running.
4. Configure the database details in `application.properties`.
5. Open the main Spring Boot application file.
6. Run the application using the **Run** button in IntelliJ IDEA.

The backend will start on the configured server port.
